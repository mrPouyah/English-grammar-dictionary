شرط و آرزو سطح B2 — میانی درس ۱۲۱

Third conditional patterns

شرطِ نوع سوم

این درس پیش‌نویس آموزشی است و بازبینی مستقل مدرس ندارد. سطح‌بندی، پیشنهاد مطالعه است و گواهی CEFR نیست.

آموزش و ساختار

شرطیِ سوم معمولاً گذشته‌ای متفاوت از آنچه واقعاً رخ داده تصور می‌کند. بند if با گذشتهٔ کامل و بند نتیجه با would have و قسمت سوم ساخته می‌شود. نتیجه می‌تواند could have یا might have هم بگیرد؛ در این صورت امکان یا عدمِ قطعیتِ نتیجه برجسته‌تر می‌شود. در این الگو هر دو بخش به گذشته مربوط‌اند، نه اینکه صرفاً صورتِ فعل‌ها گذشته باشد.

اگر می‌گوییم «اگر زودتر حرکت کرده بودیم، به قطار می‌رسیدیم»، معمولاً دیر حرکت کرده‌ایم و به قطار نرسیده‌ایم. اما برداشتِ دقیق همیشه با بافت تکمیل می‌شود. had را با have در نتیجه جابه‌جا نکنید. صورت کوتاه 'd در شرط ممکن است had و در نتیجه would باشد؛ از فعلِ بعدی می‌توان تفاوت را تشخیص داد.

بدیلِ گذشته

if + had + participle, would have + participle

If I had known, I would have helped.

اگر می‌دانستم، کمک کرده بودم.

نتیجهٔ ممکن

if + past perfect, might have + participle

If we had hurried, we might have won.

اگر عجله کرده بودیم، شاید برده بودیم.

منفیِ شرط

if + had not + participle, result

If it hadn't rained, we would have played.

اگر باران نباریده بود، بازی کرده بودیم.

روش تشخیص و نکته‌های کاربردی

برای ساختن، ابتدا واقعیتِ گذشته را بنویسید و سپس بدیلِ آن را تصور کنید. «او راهنما را نخواند» به If he had read the guide می‌رسد. در نتیجه، would have نشان می‌دهد چه اتفاقی در آن گذشتهٔ بدیل رخ می‌داد. might have فقط امکان را مطرح می‌کند و ادعای نتیجهٔ قطعی ندارد. در معیارِ آموزشی، would have را به‌طور خودکار در بند if نیاورید، هرچند چنین صورت‌هایی در بعضی گفتارها دیده می‌شوند. اگر نتیجه دربارهٔ اکنون است، ممکن است شرطیِ آمیخته لازم باشد. قسمت‌های سومِ نامنظم مانند gone، seen و taken را جداگانه کنترل کنید؛ گذشتهٔ سادهٔ آن‌ها در این زنجیره درست نیست.

مثال‌های دوزبانه

مثال ۱

If I had checked the map, I wouldn't have got lost.

اگر نقشه را بررسی کرده بودم، گم نمی‌شدم.

گوینده گذشتهٔ واقعیِ بررسی نکردن را با نتیجه‌ای متفاوت تصور می‌کند.

مثال ۲

If she had called, I would have answered.

اگر زنگ زده بود، جواب داده بودم.

هر دو عمل در گذشتهٔ بدیل قرار دارند و ساختِ کامل لازم است.

مثال ۳

We might have caught the train if we had run.

اگر دویده بودیم، شاید به قطار می‌رسیدیم.

might فقط امکانِ نتیجه را می‌رساند و رسیدن را قطعی نمی‌داند.

مثال ۴

If he hadn't warned us, we could have fallen.

اگر هشدار نداده بود، ممکن بود بیفتیم.

شرطِ منفی، نبودِ هشداری را تصور می‌کند که در واقع داده شده است.

مثال ۵

Would you have accepted if they had offered more?

اگر مبلغ بیشتری پیشنهاد کرده بودند، قبول می‌کردی؟

بند اصلی پرسشی است، ولی بند شرط ترتیبِ گذشتهٔ کامل را نگه می‌دارد.

مثال ۶

If I'd seen you, I'd have stopped.

اگر تو را دیده بودم، توقف کرده بودم.

'd اول had و 'd دوم would است؛ فعلِ بعدی تفاوت را روشن می‌کند.

مثال ۷

If we had left earlier, we could have visited the museum.

اگر زودتر رفته بودیم، می‌توانستیم موزه را ببینیم.

could have امکانِ فراهم‌شده در گذشتهٔ بدیل را برجسته می‌کند.

مثال ۸

She wouldn't have missed the meeting if the bus had arrived on time.

اگر اتوبوس به‌موقع رسیده بود، جلسه را از دست نمی‌داد.

بند شرط در پایان است و نتیجهٔ منفی همچنان کامل می‌ماند.

اشتباهات رایج فارسی‌زبان‌ها

نادرست

If I would have known, I would have helped.

درست

If I had known, I would have helped.

در معیارِ آموزشیِ شرطیِ سوم، بند if گذشتهٔ کامل می‌گیرد، نه would have.

نادرست

If she had went, she would have seen it.

درست

If she had gone, she would have seen it.

پس از had قسمت سومِ gone لازم است؛ went صورتِ گذشتهٔ ساده است.

نادرست

He would has helped if he had known.

درست

He would have helped if he had known.

پس از would، have شکل پایه دارد و نباید با فاعلِ he به has تبدیل شود.

نادرست

If we had hurried, we would have catch it.

درست

If we had hurried, we would have caught it.

در نتیجهٔ کامل، پس از have قسمت سومِ caught لازم است، نه پایهٔ catch.

نادرست

Would you accepted if they had asked?

درست

Would you have accepted if they had asked?

برای نتیجهٔ فرضیِ گذشته، would have و قسمت سوم لازم است؛ would با گذشتهٔ تنها کافی نیست.

حال و گذشتهٔ دور

If I had time, I'd help.

اگر وقت داشتم کمک می‌کردم.

If I had had time, I'd have helped.

اگر وقت داشتم، کمک کرده بودم.

had اول در دومی کمکی و had دوم قسمت سومِ have به معنیِ داشتن است.

نتیجهٔ قوی و ممکن

If we'd left earlier, we'd have caught it.

اگر زودتر رفته بودیم، به آن می‌رسیدیم.

If we'd left earlier, we might have caught it.

اگر زودتر رفته بودیم، شاید به آن می‌رسیدیم.

might اطمینان به نتیجهٔ بدیل را کمتر و بازتر بیان می‌کند.

دو جایگاهِ کوتاه‌شده

If I'd known, ...

اگر می‌دانستم، ...

... I'd have called.

... زنگ زده بودم.

'd پیش از قسمت سوم had است؛ 'd پیش از have معمولاً would است.
