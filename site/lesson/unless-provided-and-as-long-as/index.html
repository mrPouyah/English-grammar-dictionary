شرط و آرزو سطح B1 — میانی درس ۱۲۲

Unless provided and as long as

unless، provided و as long as

این درس پیش‌نویس آموزشی است و بازبینی مستقل مدرس ندارد. سطح‌بندی، پیشنهاد مطالعه است و گواهی CEFR نیست.

آموزش و ساختار

unless معمولاً به معنی «مگر اینکه» یا «اگر نه» است و یک استثنا برای نتیجه مشخص می‌کند. اگر بگوییم «می‌رویم مگر اینکه باران بیاید»، رفتن حالتِ اصلی و باران استثنایِ مانع است. آن را به‌صورت خودکار با فعلِ منفی ترکیب نکنید؛ منفیِ اضافه می‌تواند معنی را برعکس کند. unless و if را کنار هم به‌عنوان یک پیوندِ واحد نمی‌آوریم.

provided that، providing that و as long as می‌توانند شرطِ لازم برای اجازه یا توافق را بیان کنند. این‌ها فقط ترجمهٔ واژه‌به‌واژهٔ if نیستند؛ اغلب حسِ محدودیت یا تضمینِ شرط دارند. as long as در کاربردِ دیگر مدتِ زمان را می‌رساند، پس باید از بافت فهمید منظور «به شرطی که» است یا «تا وقتی که». برای آیندهٔ خنثی، بندِ شرط معمولاً صورتِ حال می‌گیرد.

استثنا

main clause + unless + present form

We'll go unless it rains.

می‌رویم مگر اینکه باران بیاید.

شرط رسمی

provided that + subject + verb

You can enter provided that you have a ticket.

به شرط داشتن بلیت می‌توانی وارد شوی.

شرطِ توافق

as long as + subject + verb

You can borrow it as long as you return it.

می‌توانی قرضش بگیری، به شرطی که پس بدهی.

روش تشخیص و نکته‌های کاربردی

برای بازنویسیِ unless، اول جمله را با except if بخوانید و سپس معادلِ if not را آزمایش کنید. در همهٔ بافت‌ها، به‌خصوص شرط‌های خلافِ واقعِ گذشته، جایگزینیِ مکانیکی طبیعی یا دقیق نیست. provided that در نوشتار رسمی و قراردادها رایج است، ولی وجودش به‌تنهایی شرطِ حقوقیِ دقیق نمی‌سازد. در مکالمه as long as اغلب طبیعی‌تر است. اگر جمله already یک منفی دارد، نقشِ هر منفی را جدا بررسی کنید؛ گاهی منفیِ بعد از unless عمدی و درست است، ولی معنای دیگری می‌سازد. برای تمرین، نتیجه را جدا بنویسید و سپس شرطِ جلوگیری‌کننده یا اجازه‌دهنده را اضافه کنید تا منطقِ جمله روشن بماند.

مثال‌های دوزبانه

مثال ۱

Unless you hurry, you will miss the train.

اگر عجله نکنی، قطار را از دست می‌دهی.

unless وضعیتِ عجله نکردن را به‌عنوان شرطِ پیامدِ منفی معرفی می‌کند.

مثال ۲

We will meet outside unless it is cold.

بیرون همدیگر را می‌بینیم مگر اینکه هوا سرد باشد.

سرد بودن استثنایی است که برنامهٔ عادیِ دیدارِ بیرون را تغییر می‌دهد.

مثال ۳

You may use the room provided that you leave it clean.

به شرطی می‌توانی از اتاق استفاده کنی که تمیز تحویلش بدهی.

شرطِ تمیز ماندن محدودیتِ اجازهٔ استفاده را مشخص می‌کند.

مثال ۴

I'll help as long as you tell me the truth.

کمک می‌کنم به شرطی که حقیقت را بگویی.

as long as شرطِ همکاری را بیان می‌کند، نه فقط مدتِ کمک را.

مثال ۵

Provided that everyone agrees, we can start on Monday.

به شرط موافقتِ همه، می‌توانیم دوشنبه شروع کنیم.

شروع برنامه به تحققِ یک شرطِ جمعی وابسته شده است.

مثال ۶

Stay as long as you like.

هرقدر دوست داری بمان.

در این جمله as long as مدتِ ماندن را بیان می‌کند، نه شرطِ اجازه را.

مثال ۷

I won't call unless there is a problem.

زنگ نمی‌زنم مگر اینکه مشکلی باشد.

قاعده تماس نگرفتن است و وجودِ مشکل استثنایِ آن محسوب می‌شود.

مثال ۸

You can take photos as long as you don't use flash.

می‌توانی عکس بگیری به شرطی که فلاش نزنی.

منفیِ داخل شرط عمدی است و رفتارِ مجاز را محدود می‌کند.

اشتباهات رایج فارسی‌زبان‌ها

نادرست

Unless if it rains, we'll go.

درست

Unless it rains, we'll go.

unless خودش پیوندِ شرط است و if را به‌عنوان پیوندِ دوم کنار آن نمی‌آوریم.

نادرست

We'll go unless it won't rain. [if it does not rain]

درست

We'll go unless it rains.

برای منظورِ «می‌رویم اگر باران نیاید»، منفیِ اضافه پس از unless معنی را برعکس می‌کند.

نادرست

You can enter provided that you has a ticket.

درست

You can enter provided that you have a ticket.

فاعلِ you فعل have می‌گیرد؛ provided that قاعدهٔ توافقِ فعل را تغییر نمی‌دهد.

نادرست

I'll help as long as you will cooperate. [neutral future]

درست

I'll help as long as you cooperate.

برای شرطِ خنثیِ آینده، حال ساده کافی است؛ will خودکار لازم نیست.

نادرست

Unless she arrives, we will starts.

درست

Unless she arrives, we will start.

پس از will فعل پایهٔ start لازم است و نشانهٔ سوم‌شخص در بندِ نتیجه نمی‌آید.

if not و unless

If you don't hurry, you'll be late.

اگر عجله نکنی دیر می‌رسی.

Unless you hurry, you'll be late.

اگر عجله نکنی دیر می‌رسی.

در این بافتِ روشن، دو الگو معنیِ اصلیِ نزدیکی دارند.

شرط و مدت

I'll help as long as you cooperate.

به شرط همکاری‌ات کمک می‌کنم.

I'll stay as long as you stay.

تا وقتی تو بمانی، من هم می‌مانم.

as long as می‌تواند شرطِ توافق یا ادامهٔ زمانی را بیان کند.

شرطِ مثبت و استثنا

We'll go if it's dry.

اگر هوا خشک باشد می‌رویم.

We'll go unless it rains.

می‌رویم مگر اینکه باران ببارد.

اولی یک شرطِ مثبت می‌گذارد؛ دومی یک استثنا را از برنامهٔ پیش‌فرض جدا می‌کند.
