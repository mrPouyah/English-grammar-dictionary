تعیین‌کننده‌ها سطح A2 — پایه درس ۳۰

Some and any

some و any

این درس پیش‌نویس آموزشی است و بازبینی مستقل مدرس ندارد. سطح‌بندی، پیشنهاد مطالعه است و گواهی CEFR نیست.

آموزش و ساختار

some و any برای اشاره به مقدار یا تعداد نامعین به کار می‌روند. some در جمله مثبت رایج است و any در منفی و پرسش خنثی بیشتر دیده می‌شود. هر دو می‌توانند با اسم جمع شمارش‌پذیر یا اسم غیرقابل‌شمارش همراه شوند. بااین‌حال، قاعده «some فقط مثبت و any فقط منفی» دقیق نیست؛ نیت گوینده و نوع سؤال اهمیت دارد.

در پیشنهاد چیزی به مخاطب یا درخواست مقداری از آن، some اغلب طبیعی است، چون وجود آن چیز را مفروض می‌گیریم یا پاسخ مثبت انتظار داریم. any در جمله مثبت می‌تواند معنای انتخاب آزاد داشته باشد: مهم نیست کدام صندلی را برگزینی. some و any گاهی بدون اسم می‌آیند، اگر مرجع از بافت روشن باشد. برای گروه مشخص دارای the یا my و برای ضمیر، معمولاً ساختار some of یا any of لازم است. این کاربردها را با معنی کامل جمله یاد بگیرید.

مقدار مثبت

some + plural/mass noun

We have some rice.

مقداری برنج داریم.

منفی

not + any + plural/mass noun

We do not have any rice.

هیچ برنجی نداریم.

انتخاب آزاد

any + singular count noun

Choose any chair.

هر صندلی‌ای را که خواستی انتخاب کن.

روش تشخیص و نکته‌های کاربردی

برای انتخاب میان این دو واژه، ابتدا به قطبیت جمله نگاه کنید، سپس منظور سؤال را بررسی کنید. Do you have any rice? یک پرسش باز درباره موجودی است. Would you like some rice? پیشنهاد پذیرایی است و some طبیعی به نظر می‌رسد. در I didn't buy any rice، any زیر دامنه منفی قرار دارد و نبود مقدار را بیان می‌کند؛ خود any به‌تنهایی معنی «هیچ» ندارد. در Choose any seat، واژه any انتخاب را آزاد می‌گذارد. در Some of the seats are wet فقط بخشی از صندلی‌های مشخص مدنظر است. برای تمرین، جمله مثبت را به منفی و سپس به پیشنهاد تبدیل کنید و تغییر معنی را همراه تغییر واژه توضیح دهید، نه اینکه تنها علامت سؤال را معیار قرار دهید.

مثال‌های دوزبانه

مثال ۱

We have some rice.

مقداری برنج داریم.

some مقدار نامعینی از اسم غیرقابل‌شمارش rice را در جمله مثبت معرفی می‌کند.

مثال ۲

We do not have any rice.

هیچ برنجی نداریم.

any همراه منفی شدن فعل، نبود مقدار برنج را در این بافت می‌رساند.

مثال ۳

Do you have any batteries?

آیا باتری دارید؟

سؤال خنثی درباره موجود بودن باتری معمولاً با any بیان می‌شود.

مثال ۴

Would you like some tea?

کمی چای میل دارید؟

این سؤال پیشنهاد پذیرایی است و some در آن کاربرد طبیعی دارد.

مثال ۵

Could I have some water?

ممکن است کمی آب به من بدهید؟

درخواست دریافت مقداری آب است؛ سؤال بودن به‌تنهایی any را الزامی نمی‌کند.

مثال ۶

You can choose any seat.

می‌توانی هر صندلی‌ای را انتخاب کنی.

any در جمله مثبت انتخاب آزاد و بی‌تفاوت بودن نسبت به گزینه را می‌رساند.

مثال ۷

Some of the windows are open.

بعضی از پنجره‌ها باز هستند.

چون منظور بخشی از پنجره‌های مشخص است، some of به کار رفته است.

مثال ۸

I have some, but I need more.

مقداری دارم، اما بیشتر لازم دارم.

اسم پس از some حذف شده چون مرجع آن در گفت‌وگو روشن است.

اشتباهات رایج فارسی‌زبان‌ها

نادرست

I don't have some money. [neutral absence]

درست

I don't have any money.

برای گزارش خنثی نبود پول، any پس از منفی طبیعی است؛ some ممکن است معنای خاص دیگری بدهد.

نادرست

some of windows

درست

some windows

وقتی اسم جمع بدون تعیین‌کننده بلافاصله می‌آید، of را به some اضافه نمی‌کنیم؛ گروه مشخص ساختار دیگری دارد.

نادرست

some the windows

درست

some of the windows

پیش از گروه اسمی دارای the، برای بیان بخشی از مجموعه به some of نیاز داریم.

نادرست

Would you like any tea? [some is forbidden]

درست

Would you like some tea?

در پیشنهاد پذیرایی، some کاملاً درست و رایج است؛ ممنوع دانستن آن در همه سؤال‌ها اشتباه است.

نادرست

You can take any books. [must mean no books]

درست

You can take any books. [free choice]

any در جمله مثبت می‌تواند انتخاب آزاد را بیان کند و به‌تنهایی جمله را منفی نمی‌کند.

مثبت و منفی

We have some rice.

مقداری برنج داریم.

We do not have any rice.

هیچ برنجی نداریم.

some و any با ساختار جمله تعامل دارند؛ any در اینجا زیر دامنه منفی است.

پرسش خنثی و پیشنهاد

Do you have any batteries?

آیا باتری دارید؟

Would you like some tea?

کمی چای میل دارید؟

هر دو سؤال‌اند، اما هدف ارتباطی متفاوت، انتخاب رایج واژه را تغییر داده است.

مقدار و انتخاب آزاد

We have some rice.

مقداری برنج داریم.

You can choose any seat.

می‌توانی هر صندلی‌ای را انتخاب کنی.

some مقدار نامعین معرفی می‌کند؛ any در جمله مثبت آزادی انتخاب را برجسته می‌کند.
